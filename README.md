# 🎯 Spelling Correction Using Closest Match

## 📝 Project Description
This project implements an intelligent spelling correction system using Python's difflib library. The system efficiently finds the closest correct sentence match for each misspelled sentence in an input file, providing accurate corrections while maintaining context.

## ✨ Features
- 🔍 Intelligent sentence matching
- 📊 High accuracy correction
- ⚡ Fast processing
- 📝 Easy-to-use interface

## 🛠️ Prerequisites
- Python 3.x
- pip (Python package installer)

## 🚀 Installation

1. Clone this repository:
```bash
git clone https://github.com/Dhyey-19/Misspelling_Correction/
cd Spelling_Correction
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## 💻 Usage

1. Prepare your input files:
   - `Problems.txt`: Contains misspelled sentences (one per line)
   - `artificial.train.tgt`: Contains correct sentences (one per line)

2. Run the script:
```bash
python main.py
```

3. Find the corrected sentences in `english_eval.corrected.txt`
